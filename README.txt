SAIKRUPA DECORATION WEBSITE
1. Extract the ZIP folder.
2. Keep index.html, style.css and the assets folder together.
3. Open index.html in a browser to preview.
4. To publish, upload all files/folders to a static host (for example GitHub Pages, Netlify or your hosting provider).
5. WhatsApp and phone buttons are configured with the numbers shown on your business card.
6. If the hero background photo does not match your preferred image, edit the background URL in style.css (search for .hero).
